Warnings

Reading the results
  • Inspect the plant fit plots first. They should look reasonable before you trust any of the numbers.
  • If the methods in the b0 table disagree significantly, use your own judgement about which fit most closely matches the recovered G.
  • Start tuning with the recovered b0 for each axis from the fit that best matches the recovered data. On a chirp flight this is usually the controller-free fit.
  • A “2nd pole above the excited band” warning, most common on yaw, means that axis wasn’t excited enough for a proper fit. Since b0 doesn’t need to be exact, the value can usually still be used without repeating the flight.
